## 🎯 Objective

The objective of this investigation is to analyze a Windows memory
image and identify suspicious processes, malicious artifacts,
network activity, and other indicators of compromise.

The investigation was performed using **Volatility 3** and focused
on process analysis, network connections, executable paths, and
memory artifacts.
