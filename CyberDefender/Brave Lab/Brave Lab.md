# CyberDefenders – Brave Lab

Windows Memory Forensics investigation focused on analyzing a memory image using **Volatility 3**.

### Objectives
- Investigate running processes and process relationships.
- Analyze network connections and command-line activity.
- Examine Brave Browser execution history using UserAssist.
- Extract forensic artifacts and identify system activity.

### Tools Used
- Volatility 3
- PowerShell
- HexEd.it
- DNSChecker
- Hash-File Online

### Key Skills
Windows Memory Forensics | Digital Forensics | Process Analysis | Network Forensics | Registry Analysis | IOC Investigation
